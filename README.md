# Bot de Marketing Inteligente para Telegram

Este é um bot completo de propaganda com:

- Pagamento automático via Mercado Pago
- Cadastro de imagem, descrição, botão e agendamento de datas/horários
- Renovação automática e edição ilimitada para anúncios ativos
- Instalação simples no Termux

## Instalação no Termux

```bash
pkg update -y && pkg upgrade -y
pkg install git python -y
pip install --upgrade pip
git clone https://github.com/douglasdias1918/bot-marketing-inteligente.git
cd bot-marketing-inteligente
pip install -r requirements.txt
python main.py
```
